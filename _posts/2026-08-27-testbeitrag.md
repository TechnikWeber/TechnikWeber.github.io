Dieser Beitrag ist ein Test, um den Weg vom Rechner bis auf die Seite einmal
komplett durchzuspielen.

## Der Ablauf

1. Datei unter `_posts/` anlegen — Dateiname immer `JJJJ-MM-TT-titel.md`
2. `git add` — Änderung zum Commit vormerken
3. `git commit` — lokal speichern
4. `git push` — zu GitHub hochladen

Danach baut GitHub Pages die Seite automatisch neu.

Wenn dieser Text online sichtbar ist, hat alles funktioniert und der Beitrag
kann wieder gelöscht werden.
